# Workflow: Старт сессии

При вызове этого workflow выполни:

1. Прочитай в строгом порядке:
   - `_ai_workspace/🧠_МОЗГ_ПРОЕКТА.md`
   - `_ai_workspace/📊_ТЕКУЩИЙ_СТАТУС.md`
   - `_ai_workspace/🔗_НЕЙРОННЫЕ_СВЯЗИ.md`

2. Выведи краткий отчёт пользователю:
   - «Текущая фаза: X. Последнее действие: Y.»
   - Незавершённые напоминания (Unity проект / GDD / GitHub — если ещё не сделано)

3. Спроси: «С какой задачи из плана начнём сегодня?»

4. Дождись ответа и приступай к работе.
