# Workflow: Перед задачей

При вызове этого workflow выполни:

1. Запусти проверку через `_ai_workspace/✅_PLAN_VALIDATION.md`:
   - Соответствует ли задача видению из `🧠_МОЗГ_ПРОЕКТА.md`?
   - Есть ли незавершённые задачи с более высоким приоритетом?

2. Проверь, не является ли задача «галлюцинацией»:
   - Не выходит ли она за рамки Фазы 0 (Проектирование)?
   - Не является ли это кодом игровой логики (запрещено до явной команды)?

3. Подтверди приоритет задачи (P0/P1/P2) и сообщи его пользователю.

4. Если нарушение → выведи предупреждение по шаблону из `✅_PLAN_VALIDATION.md` и спроси: «Продолжить? (да/нет/обсудить)»
