# Workflow: После задачи

При вызове этого workflow выполни:

1. Обнови `_ai_workspace/📊_ТЕКУЩИЙ_СТАТУС.md`:
   - Добавь запись в журнал сессий (дата + что сделано)
   - Обнови разделы «Что сделано» / «Что нужно сделать»
   - Обнови дату последнего обновления и точку остановки

2. Обнови `_ai_workspace/📈_МЕТРИКИ_ПРОГРЕССА.md`:
   - Увеличь счётчик выполненных задач
   - Обнови прогресс текущей фазы и дату

3. Обнови `_ai_workspace/🧠_SESSION_CONTEXT.md`:
   - Перезапиши секцию «СНИМОК»: фокус, сделанное, следующие шаги, хэш коммита

4. Если была ошибка — добавь урок в `_ai_workspace/📚_LESSONS_LEARNED.md`

5. Запусти Next Steps Recommender — предложи 3 следующих шага:
   ```
   🎯 РЕКОМЕНДАЦИЯ: Следующие шаги
   1. [Шаг] — [причина]
   2. [Шаг] — [причина]
   3. [Шаг] — [причина]
   ```
