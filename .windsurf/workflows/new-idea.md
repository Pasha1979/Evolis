# Workflow: Новая идея

При вызове этого workflow выполни:

1. Добавь идею в `_ai_workspace/💡_ЗАДЕЛЫ_И_ИДЕИ.md`:
   - Новый ID (следующий по порядку)
   - Статус «🔥 Новая»
   - Категория и предполагаемый приоритет

2. Задай 4 вопроса из `_ai_workspace/💡_IDEA_MANAGER.md` для анализа:
   - Соответствует ли видению из `🧠_МОЗГ_ПРОЕКТА.md`?
   - Какой приоритет (P0/P1/P2)?
   - Какие улучшения можно внести?
   - Какие риски?

3. Сообщи пользователю:
   - «Идея записана: [описание], приоритет: [P0/P1/P2]»
   - Предложи 1–2 улучшения идеи

4. НЕ начинай реализацию без команды «Одобрено, реализуй».
