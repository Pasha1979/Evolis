# Workflow: При коммите

При вызове этого workflow выполни:

1. Проверь по `_ai_workspace/🔗_НЕЙРОННЫЕ_СВЯЗИ.md`:
   - Все ли связанные файлы обновлены после изменений этой сессии?
   - Если изменился файл со связями → зависимые файлы должны быть актуальны

2. Обнови `_ai_workspace/📈_МЕТРИКИ_ПРОГРЕССА.md`:
   - Обнови дату последнего обновления
   - Увеличь счётчик коммитов

3. Проверь, что в коммит не попали:
   - Файлы из `.gitignore` (Library/, Temp/, .env и т.п.)
   - Временные файлы (`*.tmp`, `*.bak`)

4. Предложи сообщение коммита в стиле `type: описание` (feat/fix/chore/docs).
