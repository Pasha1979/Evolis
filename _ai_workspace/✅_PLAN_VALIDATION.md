## ⚠️ ФОРМАТЫ ПРЕДУПРЕЖДЕНИЙ

### Нарушение приоритетов:
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Нарушение приоритетов

Задача имеет приоритет P2, но есть незавершённые P0:
- [задача P0-1]
- [задача P0-2]

Рекомендую сначала завершить P0.
Продолжить? (да/нет/обсудить)
```

### Нарушение фазы:
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Выход за фазу

Задача относится к Фазе N, но текущая фаза — Фаза 0 (Проектирование).
В Фазе 0 игровой код не пишется.

Продолжить? (да/нет/обсудить)
```

### Нарушение видения:
```
⚠️ ПРЕДУПРЕЖДЕНИЕ: Конфликт с видением

Задача предполагает [X], что противоречит видению:
«Игрок делегирует землю институтам, а не строит напрямую».

Обсудить с пользователем.
```
