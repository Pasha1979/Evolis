## 📖 ЖУРНАЛ УРОКОВ

### Сессия 2026-11-05 — Инициализация

#### Урок 1: Неполный перенос системы управления (процессный)
**Проблема:** При создании `_ai_workspace` по ТЗ были созданы 9 файлов, но `SESSION_CONTEXT` и `LESSONS_LEARNED` из эталона kinoplan не были предложены — пробел выявлен только при внешнем сравнении.
**Решение:** Добавлены оба файла (компактно: протокол + снимок в одном файле вместо 3 файлов kinoplan).
**Предотвращение:** При выполнении ТЗ сверять список с реальными возможностями эталона и предлагать недостающее — не ограничиваться буквой задания.

---

#### Урок 2: Шаблон URP = только новый Input System (технический, предотвращён)
**Проблема:** План атомарных шагов предполагал классический `Input.GetMouseButtonDown`, но Unity 6 URP-шаблон ставит `activeInputHandler: 1` — только новый Input System. Старый API выбрасывает `InvalidOperationException` в рантайме.
**Решение:** Проверили `ProjectSettings.asset` до написания кода, обновили план: `Mouse.current` / `Keyboard.current` из `UnityEngine.InputSystem`.
**Предотвращение:** Перед кодом, зависящим от настроек проекта (ввод, рендер, физика), проверять `ProjectSettings.asset` и `manifest.json`, а не предполагать дефолты.
