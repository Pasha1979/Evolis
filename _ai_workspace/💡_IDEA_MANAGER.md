> **Назначение:** Правила записи, анализа и приоритизации идей.
>
> **Хранилище идей:** `💡_ЗАДЕЛЫ_И_ИДЕИ.md` (этот файл — процесс, тот — данные).

---

🔗 НЕЙРОННЫЕ СВЯЗИ:
- Зависит от: `🧠_МОЗГ_ПРОЕКТА.md`
- Обновляет при изменении: `🗺️_ПЛАН_РАЗРАБОТКИ.md`, `📊_ТЕКУЩИЙ_СТАТУС.md`

---

## 🔍 КАК АНАЛИЗИРОВАТЬ НОВУЮ ИДЕЮ

При появлении идеи (от пользователя или AI) выполнить 4 вопроса:

1. **Соответствует ли видению** из `🧠_МОЗГ_ПРОЕКТА.md`?
   - Не противоречит ли принципу «игрок делегирует, а не строит»?
   - Усиливает ли ключевые механики?
2. **Какой приоритет?**
   - `P0` — блокирует ядро игры (зонирование, институты)
   - `P1` — важно для глубины (эпохи, наследие)
   - `P2` — улучшение, можно позже
3. **Какие улучшения можно внести?** — предложить 1-2 варианта развития идеи
4. **Какие риски?** — сложность, производительность, scope creep

## 📋 СТАТУСЫ ИДЕЙ

| Статус | Значение |
|--------|----------|
| 🔥 Новая | Только что записана, не анализировалась |
| 💭 На анализе | Проверяем соответствие видению |
| 📅 В план | Одобрена, добавлена в план работ |
| 🚀 В работе | Реализуется (по команде пользователя!) |
| ✅ Реализовано | Полностью реализована |
| ⏸️ Отложено | Вернёмся позже |
| 🧊 Заморожено | Нет ресурсов / технических возможностей |
| ❌ Отменено | Не подходит под видение |
