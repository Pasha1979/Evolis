# 🏛️ Реестр зданий и улучшений Evolis

> **Назначение:** Единый справочник всех зданий игры: улучшения, работники, кто строит (ИИ-агент / мэр / институт), связи с ресурсами и агентами. Основа для будущей базы данных зданий в коде.
> **Статус:** Живой документ (v1.0). Авто-пополняется.
> **Связи:** `01_Game_Design_Document.md` (§3.1–3.5, §7), `02_Production_Chains_and_Resources.md` (цепочки, реестр ресурсов).

## 📜 Протокол авто-пополнения (обязателен)

При появлении **нового утверждённого здания** в любом обсуждении AI обязан:
1. Задать пользователю вопросы для полной детализации (если данных не хватает): работники, вход/выход, апгрейды, эпоха, строитель, особенности
2. После ответа — автоматически вписать здание в реестр в нужную категорию
3. Обновить связи с ресурсами (`02_...`) и цепочками

**Формат записи:** | Здание | Эпоха | Строитель | Работники | Вход → Выход | Линейка улучшений | Особенности/механики |

**Обозначения строителя:** 🤖 = ИИ-агент, 🏛️ = мэр (муниципальное), ⛪ = институт (церковь/гильдия), 🤝 = совместно

## 📝 Примечания

1. **Числа работников** — ориентировочные диапазоны для прототипа; баланс уточняется.
2. **Линейки улучшений** — здание либо апгрейдится на месте, либо заменяется новым уровнем (решение агента/игры).
3. **Перекрёстный спрос** — каждая цепочка улучшений тянет ресурсы из других отраслей (принцип `02_...`).
4. **Новые здания** вносятся по протоколу авто-пополнения (см. начало документа).
