## §1. Доки = данные (Single Source of Truth)

- **Единый источник правды — markdown-таблицы реестров** (02/03/04). Код не дублирует данные.
- Генерация: скрипт при коммите превращает таблицы в **JSON/ScriptableObject**.
- **Идентификаторы:**
  - `ResourceID` — из колонки «Ресурс» (02)
  - `BuildingID` — из колонки «Здание» (03)
  - `ProfessionID` / `AgentRoleID` — из (04)
  - `EraID 1–5` — единая нумерация эпох (1=Средневековье … 5=Будущее)
- Поля записей: вход, выход, эпоха, строитель, работники, апгрейды, особенности — берутся из таблиц.

## §2. Линтер консистентности (data-lint)

Проверки при генерации:
- Каждый **вход** ресурса имеет производителя
- Каждое **здание** привязано к профессии, каждая **профессия** — к рабочему месту
- `EraID` в диапазоне 1–5
- Число колонок таблицы = числу в шапке (нет съехавших строк)
- Нет «призраков»: ресурс/здание/профессия, упомянутые где-либо, зарегистрированы
- Все внутренние ссылки (§-ссылки, BuildingID…) существуют

## §3. Модель симуляции

- **Тиковая симуляция** — один тик = один игровой день.
- **УТВЕРЖДЕНО:** индивидуальная экономика только у **владельцев** (агенты Уровня 1–2); рядовые работники — **когорты по районам** (Уровень 3).
- На тик считаются: порча ресурсов, качество, мусор, налоги, потребления.
- **ECS** для массовых агентов (Уровень 3, тысячи сущностей).

## §4. Бюджет производительности (черновик)

- Цель: **10 000 домохозяйств @60fps**
- Тик симуляции ≤ **100 мс**

## §5. UI: скелет + одежда

- Один **layout** для всех эпох; на эпоху — **файл темы** (цвета, шрифты, рамки).
- Смена эпохи = подмена темы, без пересборки интерфейса (GDD §8).

## §6. ОТКРЫТЫЕ ВОПРОСЫ (ждут решения пользователя)

1. **Сжатие времени по эпохам.** Черновик расчёта: год ≈ 20 мин на скорости 1×; полный путь Средневековье→Будущее ≈ 466 ч на 1×, ≈ 58 ч на 8×. Нужна модель сжатия (разная длина игрового года по эпохам?).
2. **ИИ-города:** витрины (статистика без симуляции) vs полная симуляция соседей.
3. **Масштаб планеты:** границы карты, количество ИИ-городов, видимость.

## §7. Тесты (EditMode)

- Геометрия зон: Shoelace (площадь), ear-clipping с коллинеарными точками, самопересечения полигонов, point-in-polygon.
- Подрезка парцелл по контуру зоны (идея 025).
- Undo точки полигона.

## §8. Сохранения и версионирование

- Версия документов → **версия сейва**; при несовпадении — миграции данных.
- Сейв включает: состояние агентов, здания, реестры-версии, эпоху.
