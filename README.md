## 🎯 Концепция

Игрок начинает с небольшого средневекового поселения и ведёт город через эпохи — от деревни до мегаполиса. Ключевой принцип — **органическое развитие**: город растёт не по сетке, а по полигональным зонам, которые делегируются институтам и застраиваются процедурно.

### Ключевые механики (в проектировании)
- 🗺️ Полигональное зонирование территории
- 🏛️ Делегирование земли институтам
- 🏗️ Процедурная генерация застройки
- 🛣️ Органические дороги
- 📈 Эволюция зданий и эпох

### Ориентиры уровня качества
- Anno
- Cities: Skylines 2
- Manor Lords
